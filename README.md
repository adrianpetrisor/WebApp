A web application built with **ASP.NET Core MVC** for managing company employees. It allows users to create, update, delete, and view employee details through a clean and user-friendly interface.

## 🔧 Technologies Used

- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server
- Razor Views

## 🚀 Features

- ✅ Add new employee
- ✅ View employee list
- ✅ Edit employee information
- ✅ Delete employee
- ✅ Search and filter employees
- ✅ Client-side and server-side validation
